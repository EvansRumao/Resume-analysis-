# ResumeIQ — Resume Analyzer App

Full-stack starter project:
- **Frontend:** React + Vite
- **Backend:** FastAPI
- **NLP model:** your Colab-exported `resume_screening_model.pkl`
- **Resume formats:** PDF, DOCX, TXT
- **Features:** resume category prediction, job-description matching, skill coverage, ranked multiple resumes, CSV export

## 1. Add your trained model

Copy the pickle file generated by your Colab notebook to:

`backend/model/resume_screening_model.pkl`

The backend expects the bundle dictionary produced by the notebook, with a `model` key and optional `skills` and `metadata` keys. Only load a pickle file you created and trust.

## 2. Start the backend

From the project root:

```bash
cd backend
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1

pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API docs: http://127.0.0.1:8000/docs  
Health: http://127.0.0.1:8000/api/health

If the model isn't present, the API starts but category predictions report that the model is unavailable. Job matching can still be tested.

## 3. Start the frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL printed in the terminal (usually http://localhost:5173).

Optional API override: create `frontend/.env` with:

```text
VITE_API_BASE=http://localhost:8000
```

Restart Vite after changing `.env`.

## API endpoints

- `GET /` — API and model status
- `GET /api/health` — health check
- `POST /api/predict` — JSON body `{ "text": "...", "top_k": 5 }`
- `POST /api/match` — JSON body `{ "resume_text": "...", "job_description": "..." }`
- `POST /api/analyze` — one file + job description (multipart form)
- `POST /api/rank` — multiple files + job description (multipart form)

## Notes and limitations

- The matching score is a heuristic: 60% TF-IDF cosine similarity + 40% skill coverage. It is not a probability of job performance.
- Skill extraction is dictionary-based and will miss synonyms, context, and skills not in the list.
- Scanned/image-only PDFs need OCR; this starter detects when no text can be extracted.
- Candidate category prediction is trained on historical labels and should not be treated as a candidate quality score.
- Keep human review in the process. Evaluate errors and potential bias before any real-world use.
- Do not commit your pickle file or real resumes to a public repository.
